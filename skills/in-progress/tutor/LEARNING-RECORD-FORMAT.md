# Learning Record Format

Learning records live in `learning-records/` and use sequential names such as
`0001-explains-tcp-connection-start.md`.

```md
# {What the user demonstrated or corrected}

{What the user showed and how this changes the next beat.}
```

Write a record only for demonstrated understanding, stated prior knowledge, a
corrected misconception, or a confirmed mission change that changes what Tutor
should teach next. Do not use records as a session log.
