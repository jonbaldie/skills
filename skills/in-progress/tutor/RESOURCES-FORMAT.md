# Resources Format

`RESOURCES.md` is the short list of sources Tutor uses again. It grounds future
beats; it is not a reading list.

```md
# {Topic} Resources

## Sources

- [{Source title}]({URL})
  {Why it is trustworthy and which ideas it supports.}
```

Prefer primary sources. When one is unavailable, use the most authoritative
trustworthy source. Keep only sources that help the user's mission.
