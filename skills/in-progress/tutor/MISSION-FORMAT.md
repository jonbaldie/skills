# Mission Format

`MISSION.md` states why the user is learning this topic. Keep it short enough
to guide the next beat.

```md
# Mission: {Topic}

## Why
{The concrete outcome the user wants.}

## Success looks like
- {An observable thing the user will be able to do.}

## Constraints
- {Time, prior knowledge, preferences, or other limits.}

## Out of scope
- {A related topic the user does not want to pursue now.}
```

Revise the mission only after the user confirms their goal changed.
