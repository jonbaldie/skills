# Glossary Format

`GLOSSARY.md` contains useful terms the user has shown they understand. It is
not a list of terms the tutor has introduced.

```md
# {Topic} Glossary

**{Term}**:
{A plain, one- or two-sentence definition.}
```

Add a term only after the user uses it correctly. Prefer the glossary's terms
in later beats when they make the explanation clearer.
