---
name: options
description: Give a few options for the current decision, then recommend one.
disable-model-invocation: true
---

Use the current conversation to identify the decision and the user's priorities.

Give 2–3 viable options as a numbered list. Each gets one short sentence: the
action and its main tradeoff. Include only distinct, realistic choices.

Then write: **Recommendation:** [Choose one option] because [decisive reason
tied to the user's priorities].

Keep the entire response under 120 words. Start with the options. End with the
recommendation. Use plain, direct language.
